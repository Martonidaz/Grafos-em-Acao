## 1. Dijkstra

Desenvolver de maneira clara e objetiva um software que faça o cálculo das melhores rotas de trabalho
do transporte público de Lorena/SP. O software deverá indicar qual é o melhor caminho a seguir, depois
de decididos os pontos de Origem e Destino, com base no que se propõe o algoritmo de Dijkstra.

Elabore um Grafo que represente a cidade de Lorena, como também os pontos de parada do transporte
público (utilize o Google Maps).

## 2. Prim

Faça uma pesquisa na Web sobre os voos com ou sem escala da empresa LATAM no Brasil. Desenvolver de
maneira clara e objetiva um software que faça com que a empresa LATAM atenda toda a demanda do país de
forma que percorra somente uma via de conexão. O software deverá indicar quais são essas vias, com base
no que se propõe o algoritmo de PRIM.

Elabore um Grafo que represente os principais aeroportos do Brasil e as vias de conexões padrão da
empresa LATAM, como também os pontos de escala (utilize o Google Maps).

## 3. Kruskal

Desenvolver de maneira clara e objetiva um software que faça com que um prefeito tenha condição de
pavimentar uma determinada cidade, porém como o recurso financeiro é escasso o prefeito precisará de um
software que determine quais são as vias de menor tamanho na cidade que interligam todos os bairros;
somente as vias de menor tamanho serão pavimentadas. O software deverá indicar quais são essas vias,
com base no que se propõe o algoritmo de KRUSKAL.

Elabore um Grafo que represente a cidade em questão e suas vias de acesso (utilize o Google Maps).
