Como o algoritmo funciona?

Objetivo

Encontrar o caminho de menor custo total entre a origem e o destino escolhidos.

Vértices, arestas e pesos

Cada vértice é um ponto de parada; cada aresta é um trecho entre dois pontos; o peso é a distância estimada do trecho em km.

Critério de escolha

A cada etapa, visita o ponto ainda não visitado que tem a menor distância acumulada desde a origem. Depois tenta melhorar a distância dos vizinhos: se dist[atual] + peso < dist[vizinho], atualiza.

Como chega ao resultado

Quando o destino é visitado, sua distância é definitiva. O caminho é reconstruído de trás para frente usando o campo anterior de cada ponto.

Por que é adequado

Num sistema de transporte, o passageiro quer o trajeto mais curto entre dois pontos. Como as distâncias nunca são negativas, Dijkstra garante o ótimo.

dist[v] = ∞ para todo v;  dist[origem] = 0
enquanto houver vértice não visitado:
    u = vértice não visitado com menor dist[u]
    marca u como visitado            (se u == destino: para)
    para cada vizinho v de u:
        se dist[u] + peso(u,v) < dist[v]:
            dist[v] = dist[u] + peso(u,v);  anterior[v] = u
caminho = destino → anterior → ... → origem   (invertido)
